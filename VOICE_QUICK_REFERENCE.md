# 🎙️ Elizabeth Voice Commands - Quick Reference

## Activation

Say any of these to wake Elizabeth:
```
"Elizabeth"
"Hey Elizabeth"
"Hi Elizabeth"
"Hello Elizabeth"
```

**Elizabeth responds:** "Yes, I'm here. How can I help you?"

---

## Navigation Commands

| Say This | Result |
|----------|--------|
| "open projects" | Opens Projects page |
| "code editor" | Opens Code Editor |
| "show me the code" | Opens Code Editor |
| "open chat" | Opens AI Chat |
| "chat" | Opens AI Chat |
| "show me the team" | Opens Team page |
| "team" | Opens Team page |
| "open settings" | Opens Settings |
| "settings" | Opens Settings |

---

## Action Commands

| Say This | Result |
|----------|--------|
| "create a new project" | Opens Projects view |
| "new project" | Opens Projects view |
| "help" | Explains capabilities |
| "what can you do?" | Lists features |

---

## End Conversation

| Say This | Result |
|----------|--------|
| "goodbye" | Ends conversation gracefully |
| "bye" | Ends conversation |
| "stop" | Stops voice assistant |

---

## Tips

✅ **Speak naturally** - No need for robot-speak
✅ **Wait for response** - Let Elizabeth finish talking
✅ **Keep talking** - Conversation stays active for 30 seconds
✅ **Use keywords** - "projects", "code", "chat" all work
✅ **Be clear** - Speak at normal volume and pace

---

## Example Conversation

```
You: "Elizabeth"
Elizabeth: "Hello! What can I do for you?"

You: "Open projects"
Elizabeth: "Opening projects view for you."
[Projects page opens]

You: "Create a new project"
Elizabeth: "Creating a new project for you."

You: "Goodbye"
Elizabeth: "Goodbye! Call me if you need anything."
```

## Troubleshooting

**Not responding?**
- Check microphone permissions
- Speak clearly
- Try "Hey Elizabeth"

**Can't hear Elizabeth?**
- Check browser audio
- Unmute tab
- Check volume

---

## Button Location

Look for **"Talk to Elizabeth"** button in the **bottom-right corner** of the screen.
