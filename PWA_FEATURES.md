# Elizabeth - Progressive Web App (PWA) Features

Elizabeth is now a **production-ready Progressive Web App** with enterprise-grade offline capabilities and native app features.

## PWA Capabilities

### 1. Installable
- **Install on Desktop**: Chrome, Edge, Firefox, Safari
- **Install on Mobile**: iOS Safari, Android Chrome
- **App Shortcuts**: Quick access to Chat, Code Editor, and New Project
- **Custom Install Prompt**: Smart timing (3 seconds after load)
- **Remember User Choice**: Won't prompt again if dismissed

### 2. Offline Support
- **Full Offline Functionality**: Works without internet
- **Smart Caching Strategy**:
  - API calls: NetworkFirst (5s timeout)
  - Static assets: StaleWhileRevalidate
  - Images: CacheFirst (30-day cache)
  - Fonts: CacheFirst (365-day cache)
  - Storage files: CacheFirst (7-day cache)
  - Edge Functions: NetworkFirst (10s timeout)

### 3. Update Management
- **Auto-update**: New versions install automatically
- **User Notification**: Elegant update prompt when available
- **Skip Waiting**: Instant updates with user consent
- **Old Cache Cleanup**: Automatic removal of outdated caches

### 4. Native App Features
- **Standalone Mode**: Runs in its own window
- **Custom Theme**: Brand colors and splash screen
- **Status Bar Integration**: Platform-native feel
- **App Shortcuts**: Right-click/long-press menu
- **Share Target**: Can receive shared content (future)

## Technical Implementation

### Service Worker
- **Generated by**: Workbox (Google)
- **Mode**: GenerateSW (automatic)
- **Registration**: Auto-update on page load
- **Precached Assets**: 12 files (565 KB)
- **Runtime Caching**: 6 strategies

### Caching Details

#### API Caching (NetworkFirst)
- Timeout: 5 seconds
- Max Entries: 100
- Max Age: 5 minutes
- Falls back to cache if network fails

#### Storage Caching (CacheFirst)
- Max Entries: 50
- Max Age: 7 days
- Perfect for avatars and uploads

#### Image Caching (CacheFirst)
- Max Entries: 100
- Max Age: 30 days
- Supports: PNG, JPG, SVG, WebP

#### Edge Function Caching (NetworkFirst)
- Timeout: 10 seconds
- Max Entries: 30
- Max Age: 5 minutes

### Update Flow
1. Service worker detects new version
2. Downloads new assets in background
3. Shows update notification to user
4. User clicks "Update Now"
5. Service worker activates new version
6. Page reloads with new code

## Troubleshooting

### Install Prompt Not Showing
- Clear browser cache
- Check HTTPS is enabled
- Verify manifest.json is valid
- Check for service worker errors

### Offline Mode Not Working
- Verify service worker is registered
- Check cache strategies
- Clear caches and retry
- Check network tab in DevTools

### Updates Not Applying
- Hard refresh (Ctrl+Shift+R)
- Clear service worker cache
- Unregister and re-register SW
- Check for SW errors in console
